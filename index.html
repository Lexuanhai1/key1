📖 Cách dùng — web key KHÔNG liên quan tới build plugin
  1. Tạo key ở form bên dưới → bấm 📋 Copy gửi cho khách, hoặc…
  2. Bấm ⬇️ Export keys.json → lấy file keys.json đặt vào plugins/AuthPremium/keys.json của server con (plugin đọc file này để xác thực key, tự nạp lại mỗi phút).
  3. Khách gõ /atp key <KEY> (hoặc ghi key vào key.txt rồi /atp reload) — key nằm trong keys.json và còn hạn là dùng được.
  4. Xoá / Chặn key ở đây → export lại keys.json đưa lên server → plugin tự khoá key đó trong ≤ 1 phút.
  5. Toàn bộ dữ liệu lưu trong trình duyệt này (localStorage). Muốn chuyển máy: Export → Import ở máy mới.
